# State Language

## 🆕 What's New

- **[2026.11.22] State Language** - `0.2.0-hello-world`, SMSL is now State Language!
- **[2025.04.19] PySMSL 0.1.x** - Versions 0.1.0 and 0.1.1 arrived on PyPI. Python users could load a state machine, plot its branches with NetworkX and Matplotlib, and query the shortest path between states. [PyPI release history](https://pypi.org/project/pysmsl/#history)
- **[2023.12.05] Tower of Hanoi demo** - The demo loaded a graph of board positions from JSON, found the shortest sequence of legal moves between two positions, and animated the solution.
- **[2023.12.04] First Python release** - SMSL began as `pysmsl`, a Python library for serializing finite-state machines. [PySMSL 0.0.1](https://pypi.org/project/pysmsl/0.0.1/)
